# رمز التحقق عند تسجيل دخول ووردبريس

يضيف رمز تسجيل الدخول خطوة ثانية بعد اسم مستخدم وكلمة مرور صحيحين، ويكون التفعيل اختياريًا للموقع والمستخدم معًا.

## نموذج الأمان

- الميزة معطلة افتراضيًا ولا يُضم المستخدمون الحاليون.
- كلمة المرور الخاطئة لا ترسل رمزًا.
- لا ينشئ ووردبريس cookie مصادقة قبل نجاح OTP.
- يرتبط التحدي بمستخدم واحد ورمز 256 بت داخل cookie بخصائص `HttpOnly` و`SameSite=Lax`.
- لا يظهر رمز التحدي في الرابط أو الصفحة أو سجل المتصفح.
- يُحذف التحدي الناجح أو المنتهي قبل اكتمال الدخول.
- تنهي خمس محاولات محلية فاشلة التحدي.
- تمر التحويلات عبر تحقق ووردبريس الآمن.

## التفعيل وضم المستخدم

1. أكمل اختبار OTP ناجحًا.
2. فعّل **السماح برمز التحقق عند تسجيل دخول ووردبريس** من **Ersaal ← الإعدادات ← رمز التحقق**.
3. افتح ملف المستخدم وأدخل هاتفًا دوليًا.
4. أرسل رمز الملف الشخصي وتحقق منه.
5. فعّل **طلب رمز تحقق بعد كلمة مرور ووردبريس** واحفظ.

لا يغيّر التفعيل العام أي مستخدم وحده. يؤدي تغيير الهاتف أو حذفه إلى إزالة التحقق وتعطيل OTP، ويجب التحقق من الرقم البديل ثم الاشتراك مجددًا بوضوح.

## تجربة الدخول

بعد قبول كلمة المرور ترسل Ersaal الرمز وتظهر شاشة تحقق مستقلة. لا ينشئ ووردبريس جلسته المعتادة إلا بعد نجاح الرمز. يبقى زر إعادة الإرسال معطلًا حتى انتهاء الرمز النشط، ولا يمكن إعادة استخدام رمز ناجح.

## الاستعادة الطارئة

أضف إلى `wp-config.php`:

```php
define('ERSAAL_DISABLE_LOGIN_OTP', true);
```

يتجاوز هذا الثابت OTP لتسجيل الدخول فقط، وتبقى الاختبارات والسجلات وواجهة المطور والرسائل ووكومرس والإعدادات متاحة. احذفه أو اجعله `false` بعد الحل.

للمستخدم المشترك تفشل المصادقة بكلمة المرور خارج `wp-login.php` التفاعلية، حتى لا تتجاوز XML-RPC أو REST أو AJAX أو المسارات غير التفاعلية الخطوة الثانية.
