# دليل إعداد رمز التحقق

دعم رموز التحقق اختياري ومعطل افتراضيًا. لا تؤدي الترقية إلى ضم المستخدمين أو تغيير تسجيل دخول ووردبريس.

## المتطلبات

- اتصال صالح بواجهة Ersaal API.
- اسم مرسل نشط ومعتمد ومتوافق مع مزود الرقم.
- رصيد محفظة أو باقة رموز تحقق بها وحدات متاحة.
- رقم هاتف دولي مثل `+2189XXXXXXXX`.

## الإعداد والاختبار

1. افتح **Ersaal ← الإعدادات ← رمز التحقق** وفعّل خدمات OTP.
2. اختر المرسل والمحفظة أو الباقة وطول 4 أو 6 أرقام ومدة من دقيقة إلى 10 دقائق والعربية أو الإنجليزية أو اللغة التلقائية.
3. احفظ، ثم افتح **Ersaal ← اختبار رمز التحقق**.
4. أدخل الهاتف مع مفتاح الدولة وأرسل الرمز.
5. أدخل الرمز قبل انتهاء صلاحيته وتحقق منه.
6. راجع السجل الآمن في **Ersaal ← نشاط رموز التحقق**.

تتبع اللغة التلقائية لغة ووردبريس. قد يستهلك الإرسال الحقيقي رصيد المحفظة أو وحدة من الباقة. تحتفظ الحالة المؤقتة بالهاتف والمرجع خلال نافذة التحقق القصيرة فقط، ولا يُحفظ الرمز مطلقًا.

## النشاط والخصوصية

يتضمن سجل OTP نوع العملية ونتيجتها ومسارها والهاتف المخفي وبصمة أحادية الاتجاه والمرجع الآمن وحالة HTTP وملخص خطأ منقح. ولا يتضمن الرمز أو الهاتف كاملًا أو بيانات API أو كلمة المرور أو cookie المصادقة.

## الأخطاء الشائعة

- **المصادقة:** تحقق من مفتاح API وحالة المشروع والشركة وقائمة IP.
- **المرسل:** اختر مرسلًا نشطًا معتمدًا ومتوافقًا مع مزود الرقم.
- **الرصيد أو الباقة:** اشحن المحفظة أو اختر باقة بها وحدات OTP.
- **رمز نشط:** استخدم الرمز الحالي أو انتظر انتهاء مدته.
- **منتهي أو مستخدم:** أرسل رمزًا جديدًا؛ لا يمكن إعادة استخدام الرمز الناجح.
- **تقييد المعدل:** انتظر مدة إعادة المحاولة.
- **الخدمة غير متاحة:** حاول لاحقًا وراجع الاتصال وحالة Ersaal.
